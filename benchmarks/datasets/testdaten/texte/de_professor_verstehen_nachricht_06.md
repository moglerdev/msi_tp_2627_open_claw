Die Replikation bleibt unzugänglich, solange Code und Datensatz nicht abgelegt sind. Code und Datensatz im Repositorium ablegen. Die Frist dafür ist der 31. August 2026. Der Ort ist das Institutsrepositorium, Leibnizstraße 8, Kiel. Ich stufe die Dringlichkeit als mittel ein. Das ist wichtig. Bitte legen Sie Code und Datensatz in einer einander zugeordneten Fassung ab, sodass eine lesende Person beide ohne weitere Nachfrage findet. Die Fakultät erwartet keine neue Auswertung und keine nachträgliche Änderung der Replikation, sondern die Ablage dessen, was der Replikation zugrunde liegt. Kennzeichnen Sie die Fassung so, dass sie von älteren Arbeitsständen unterscheidbar ist. Lassen Sie Zwischendateien weg, die nicht zur Replikation gehören, und fügen Sie keine Erläuterung hinzu, die den Code ersetzen soll. Eine knappe Leseanweisung darf auf der Ablage selbst stehen, sofern sie nicht eine zweite, abweichende Fassung beschreibt. Halten Sie die Bezeichnung von Code und Datensatz gleich, damit die Zuordnung nicht erst mündlich hergestellt werden muss. Die Replikation soll nach der Ablage aus den abgelegten Stücken allein nachvollziehbar sein. Bitte prüfen Sie vor der Ablage, ob der Code auf dem abgelegten Datensatz auch wirklich läuft. Die Fakultät erwartet keine Schönung der Ausgabe und keine stillschweigend andere Fassung. Was abgelegt ist, soll das sein, worauf die Replikation sich stützt. Ein bloßer Hinweis auf einen anderen Speicher genügt nicht.
